## Comment remplir

- **Arrivée / départ** : l'heure où vous commencez et finissez de travailler sur l'ordinateur
  (pas l'heure d'entrée dans les locaux).
- **Pause** : déjeuner et pauses sans ordinateur, en minutes.
- **Dossiers** : le code du dossier (`GIC-HYD-ETU-052`, `2026-SOMAPEP-001`…) et le nombre d'heures
  approximatif, au quart d'heure près. Deux colonnes suffisent ; au-delà, écrivez au dos.
- **Autre** : tout ce qui n'est pas un dossier : réunions, courriels généraux, formation, terrain
  sans ordinateur. L'agent ne voit pas le terrain : c'est normal que cette colonne diverge.
- **Remarque** : tout ce qui peut expliquer un écart (ordinateur éteint, réseau coupé, travail
  sur un autre poste, télétravail).

## Ce que l'agent mesure, pour mémoire

Le temps actif sur votre poste, rattaché aux dossiers par le dossier dans lequel sont rangés les
fichiers ouverts. Il ne lit ni le contenu des fichiers, ni les courriels, ni les sites visités
(seul le nom d'un PDF ouvert dans le navigateur est retenu). Vous voyez votre propre journée dans
« Mon activité du jour » (icône près de l'horloge). Détail : note d'information D01.

## Après la semaine

Remettez la feuille au responsable du pilote. La comparaison (D04) donne, par jour : heures
mesurées, heures déclarées, écart ; et par dossier : la répartition mesurée contre la vôtre. Les
écarts sont discutés avec vous avant toute correction de l'agent.
